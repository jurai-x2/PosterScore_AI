# RELEASE-001 — PosterScore AI MVP Baseline

Date recorded: 2026-11-02

This release note represents the earliest known documented baseline, not a claim about the original release date. It contains the current full-stack MVP described in `PROJECT_OVERVIEW.md` and `FEATURE_REGISTRY.md`.

## Verification

- Tests: run with `npm test`.
- Production build: run with `npm run build`.
- Local development: run with `npm run dev`.

## Scope

Upload and review workflow, image preprocessing, Gemini analysis, deterministic scoring/rules, structured critique, priority recommendations, markers, browser history, print export, demo mode, and CI.

## Not included

PostgreSQL persistence, server-side history analytics, authentication, and Vercel/Render deployment configuration.
